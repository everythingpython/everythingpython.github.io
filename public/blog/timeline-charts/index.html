Timeline charts

20 Nov, 2024

I’m not feeling all too well but I didn’t want to break my streak of writing. So today I’m writing about a non-Python related topic - Timeline Charts.

I was doing a profiling activity for work and I was scratching my head for a way to represent the info so as to explain it easily. Then I got to thinking, how does Google build all those charts to track page loads and API runtimes in Developer tools?

Turns out it’s something called Timeline Charts that Google’s made available for everyone.

Here’s an example -

 1<html>
 2  <head>
 3    <script type="text/javascript" src="https://www.gstatic.com/charts/loader.js"></script>
 4    <script type="text/javascript">
 5      google.charts.load('current', {'packages':['timeline']});
 6      google.charts.setOnLoadCallback(drawChart);
 7      function drawChart() {
 8        var container = document.getElementById('timeline');
 9        var chart = new google.visualization.Timeline(container);
10        var dataTable = new google.visualization.DataTable();
11
12        dataTable.addColumn({ type: 'string', id: 'President' });
13        dataTable.addColumn({ type: 'date', id: 'Start' });
14        dataTable.addColumn({ type: 'date', id: 'End' });
15        dataTable.addRows([
16          [ 'Washington', new Date(1789, 3, 30), new Date(1797, 2, 4) ],
17          [ 'Adams',      new Date(1797, 2, 4),  new Date(1801, 2, 4) ],
18          [ 'Jefferson',  new Date(1801, 2, 4),  new Date(1809, 2, 4) ]]);
19
20        chart.draw(dataTable);
21      }
22    </script>
23  </head>
24  <body>
25    <div id="timeline" style="height: 180px;"></div>
26  </body>
27</html>
